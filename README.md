# เว็บรับสมัครงาน — บริษัท อินฟินิตี้ บลู จำกัด

เว็บหน้าเดียว (`index.html`) ไม่ต้องติดตั้งอะไร เปิดไฟล์หรืออัปขึ้นโฮสต์ใดก็ได้ (GitHub Pages, Netlify, Cloudflare Pages)

## ผู้สมัครทำอะไรบ้าง (4 ขั้นตอน)
1. **ใบสมัคร** — ครบทุกช่องตามใบสมัครเดิม เพิ่ม "วันเกิด" (ใช้คำนวณอายุและเลขศาสตร์), "เงินเดือนที่คาดหวัง", "Portfolio" และให้เลือกตำแหน่งจาก 7 ตำแหน่ง พร้อมเซ็นชื่อ
2. **DISC** 24 ข้อ — เลือกคำที่ตรงกับตัวเองที่สุด → สัดส่วน D / I / S / C
3. **BOSI** 16 ข้อ — Builder / Opportunist / Specialist / Innovator
4. **Enneagram** 36 ข้อ (ให้คะแนน 1–5) → ไทป์หลัก 1–9 และไทป์รอง

ระบบบันทึกร่างอัตโนมัติ ถ้าปิดหน้าเว็บไปแล้วกลับมาก็ทำต่อได้

## ฝ่ายบุคคลดูผล
เปิด `index.html#hr` (หรือกดลิงก์ "สำหรับเจ้าหน้าที่ HR" ท้ายหน้า)
- ดูผลทดสอบทั้ง 3 ชุด และ **% ความเหมาะสมกับทั้ง 7 ตำแหน่ง** (แยก DISC / BOSI / Enneagram และค่ารวม)
- ดู **ความเข้ากันได้กับ CEO** ตามเลขศาสตร์พีทาโกรัส
- พิมพ์ลงกระดาษ A4: **ผลประเมิน (1 หน้า)**, **ใบสมัคร (รูปแบบเดิม)** หรือ **ทั้งหมด**
- บันทึกส่วน HR (สถานะ, เงินเดือน, วันเริ่มงาน, บันทึกสัมภาษณ์) และคัดลอกเป็น CSV ไปวางใน Excel

## วิธีคิดคะแนน
| แบบทดสอบ | วิธีคิด % ความเหมาะสม |
|---|---|
| DISC | ความทับซ้อนระหว่างสัดส่วน D/I/S/C ของผู้สมัคร กับโปรไฟล์ในอุดมคติของตำแหน่ง |
| BOSI | ความทับซ้อนระหว่างสัดส่วน B/O/S/I ของผู้สมัคร กับโปรไฟล์ในอุดมคติของตำแหน่ง |
| Enneagram | คะแนนของไทป์หลัก × 65% + ไทป์รอง × 35% จากตารางคะแนนของแต่ละตำแหน่ง |
| รวม | ค่าเฉลี่ยของ 3 แบบทดสอบ: 80%+ เหมาะมาก · 70–79% เหมาะ · 60–69% พอใช้ · ต่ำกว่า 60% ไม่ค่อยเหมาะ |

ปรับโปรไฟล์ในอุดมคติของแต่ละตำแหน่งได้ที่ตัวแปร `POSITIONS` ด้านบนของสคริปต์ใน `index.html`

**เลขศาสตร์ (พีทาโกรัส):** บวกเลขทุกหลักของวันเกิด (ค.ศ.) แล้วบวกซ้ำจนเหลือหลักเดียว ยกเว้นเลขมาสเตอร์ 11/22/33
CEO เกิด 22/04/1988 (2531) → 2+2+0+4+1+9+8+8 = 34 → 7 แล้วใช้คะแนนจากไฟล์ `numerology_compatibility_7.xlsx` (ตัวแปร `NUM`)
ถ้าเปลี่ยน CEO เป็นคนที่เลขไม่ใช่ 7 ต้องแก้ตาราง `NUM` ด้วย

> แบบทดสอบเป็นฉบับย่อที่ทำขึ้นเพื่อใช้ประกอบการสัมภาษณ์ ควรใช้ร่วมกับการสัมภาษณ์และการทดสอบทักษะ ส่วนเลขศาสตร์ไม่มีหลักฐานทางวิทยาศาสตร์รองรับ จึงไม่ควรใช้เป็นเกณฑ์ตัดสินการจ้างงาน

## ⚠️ ข้อมูลเก็บที่ไหน
ข้อมูลเก็บใน **เบราว์เซอร์ของเครื่องที่ใช้กรอก** (localStorage) เหมือนไฟล์เดิม
- **ใช้ได้ทันที:** ให้ผู้สมัครกรอกบนแท็บเล็ตหรือคอมพิวเตอร์ของบริษัท แล้ว HR เปิด `#hr` บนเครื่องเดียวกัน
- **ให้ผู้สมัครกรอกจากมือถือตัวเอง:** ต้องส่งข้อมูลเข้า Google Sheets ตามขั้นตอนด้านล่าง

### ส่งข้อมูลเข้า Google Sheets (ไม่บังคับ)
1. สร้าง Google Sheet ใหม่ → เมนู Extensions → Apps Script แล้ววางโค้ดนี้:
```js
function doPost(e) {
  const a = JSON.parse(e.postData.contents);
  const ss = SpreadsheetApp.getActive();
  const sh = ss.getSheetByName('applicants') || ss.insertSheet('applicants');
  if (sh.getLastRow() === 0) sh.appendRow(['เวลา', 'ชื่อ', 'ตำแหน่ง 1', 'โทร', 'อีเมล', 'json']);
  let j = JSON.stringify(a);
  if (j.length > 49000) j = JSON.stringify(Object.assign({}, a, { signImg: '' })); // 1 ช่องเก็บได้ไม่เกิน 50,000 ตัวอักษร
  sh.appendRow([new Date(), a.nameTh, a.pos1, a.phone, a.email, j]);
  return ContentService.createTextOutput('ok');
}
```
2. Deploy → New deployment → Web app → Execute as: Me, Who has access: Anyone → คัดลอก URL
3. ใส่ URL ใน `CONFIG.submitUrl` ใน `index.html`
4. วิธีดูผลหรือพิมพ์: คัดลอกช่อง `json` ของผู้สมัคร → เปิด `#hr` → กด "นำเข้าข้อมูลผู้สมัคร (JSON)"
