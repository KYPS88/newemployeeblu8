# เว็บรับสมัครงาน — บริษัท อินฟินิตี้ บลู จำกัด

เว็บหน้าเดียว (`index.html`) ไม่ต้องติดตั้งอะไร เปิดไฟล์หรืออัปขึ้นโฮสต์ใดก็ได้ (GitHub Pages, Netlify, Cloudflare Pages)

## ผู้สมัครทำอะไรบ้าง (4 ขั้นตอน)
1. **ใบสมัคร** — ครบทุกช่องตามใบสมัครเดิม เพิ่ม "วันเกิด" (ใช้คำนวณอายุและเลขศาสตร์), "เงินเดือนที่คาดหวัง", "Portfolio" และให้เลือกตำแหน่งจาก 7 ตำแหน่ง พร้อมเซ็นชื่อ
2. **DISC** 24 ข้อ — เลือกคำที่ตรงกับตัวเองที่สุด → สัดส่วน D / I / S / C
3. **BOSI** 16 ข้อ — Builder / Opportunist / Specialist / Innovator
4. **Enneagram** 36 ข้อ (ให้คะแนน 1–5) → ไทป์หลัก 1–9 และไทป์รอง

ระบบบันทึกร่างอัตโนมัติ ถ้าปิดหน้าเว็บไปแล้วกลับมาก็ทำต่อได้

## ฝ่ายบุคคลดูผล
เปิด `index.html#hr` (หรือกดลิงก์ "สำหรับเจ้าหน้าที่ HR" ท้ายหน้า)
- ดูผลทดสอบทั้ง 3 ชุด และ **% ความเหมาะสมกับทั้ง 7 ตำแหน่ง** (แยก DISC / BOSI / Enneagram และค่ารวม)
- ดู **ความเข้ากันได้กับ CEO** ตามเลขศาสตร์พีทาโกรัส
- พิมพ์ลงกระดาษ A4: **ผลประเมิน (1 หน้า)**, **ใบสมัคร (รูปแบบเดิม)** หรือ **ทั้งหมด**
- บันทึกส่วน HR (สถานะ, เงินเดือน, วันเริ่มงาน, บันทึกสัมภาษณ์) และคัดลอกเป็น CSV ไปวางใน Excel

## วิธีคิดคะแนน
| แบบทดสอบ | วิธีคิด % ความเหมาะสม |
|---|---|
| DISC | ความทับซ้อนระหว่างสัดส่วน D/I/S/C ของผู้สมัคร กับโปรไฟล์ในอุดมคติของตำแหน่ง |
| BOSI | ความทับซ้อนระหว่างสัดส่วน B/O/S/I ของผู้สมัคร กับโปรไฟล์ในอุดมคติของตำแหน่ง |
| Enneagram | คะแนนของไทป์หลัก × 65% + ไทป์รอง × 35% จากตารางคะแนนของแต่ละตำแหน่ง |
| รวม | ค่าเฉลี่ยของ 3 แบบทดสอบ: 80%+ เหมาะมาก · 70–79% เหมาะ · 60–69% พอใช้ · ต่ำกว่า 60% ไม่ค่อยเหมาะ |

ปรับโปรไฟล์ในอุดมคติของแต่ละตำแหน่งได้ที่ตัวแปร `POSITIONS` ด้านบนของสคริปต์ใน `index.html`

**เลขศาสตร์ (พีทาโกรัส):** บวกเลขทุกหลักของวันเกิด (ค.ศ.) แล้วบวกซ้ำจนเหลือหลักเดียว ยกเว้นเลขมาสเตอร์ 11/22/33
CEO เกิด 22/04/1988 (2531) → 2+2+0+4+1+9+8+8 = 34 → 7 แล้วใช้คะแนนจากไฟล์ `numerology_compatibility_7.xlsx` (ตัวแปร `NUM`)
ถ้าเปลี่ยน CEO เป็นคนที่เลขไม่ใช่ 7 ต้องแก้ตาราง `NUM` ด้วย

> แบบทดสอบเป็นฉบับย่อที่ทำขึ้นเพื่อใช้ประกอบการสัมภาษณ์ ควรใช้ร่วมกับการสัมภาษณ์และการทดสอบทักษะ ส่วนเลขศาสตร์ไม่มีหลักฐานทางวิทยาศาสตร์รองรับ จึงไม่ควรใช้เป็นเกณฑ์ตัดสินการจ้างงาน

## เปิดให้ผู้สมัครกรอกจากมือถือ

ลิงก์หน้าเว็บ (GitHub Pages): **https://kyps88.github.io/newemployeeblu8/**
ลิงก์หน้า HR: **https://kyps88.github.io/newemployeeblu8/#hr**

### 1) เปิด GitHub Pages (ทำครั้งเดียว)
GitHub → repo นี้ → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `claude/nice-clarke-y97yo3` โฟลเดอร์ `/ (root)` → Save
รอ 1–2 นาที แล้วลิงก์ด้านบนจะใช้งานได้

### 2) เชื่อม Google Sheets เพื่อเก็บข้อมูลผู้สมัคร (ทำครั้งเดียว ประมาณ 5 นาที)
หน้าเว็บบน GitHub เป็นไฟล์ธรรมดา ไม่มีที่เก็บข้อมูล จึงต้องส่งข้อมูลไปเก็บใน Google Sheets ของบริษัท
1. สร้าง Google Sheet ใหม่ (เช่นชื่อ "ผู้สมัครงาน") → เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางโค้ดจากไฟล์ [`apps-script/Code.gs`](apps-script/Code.gs)
3. **ตั้งรหัสผ่าน HR** ที่บรรทัด `const HR_PASSWORD = '...'` (อย่าใส่รหัสจริงลงใน GitHub เพราะ repo นี้เป็นสาธารณะ)
4. กดปุ่ม **+ (เพิ่มไฟล์) → HTML** ตั้งชื่อ `index` แล้ววางโค้ดทั้งหมดจาก `index.html` (ใช้กรณีต้องการเปิดเว็บผ่านลิงก์ของ Google แทน GitHub)
5. กด **Deploy → New deployment** → ประเภท **Web app** → Execute as: **Me** → Who has access: **Anyone** → Deploy → อนุญาตสิทธิ์
6. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`) แล้วใส่ใน `index.html` ที่ `CONFIG.apiUrl` (หรือส่งให้ Claude ใส่ให้)

**ข้อมูลใน Google Sheet** (แท็บ "ผู้สมัคร"): 1 แถวต่อผู้สมัคร 1 คน 1 คอลัมน์ต่อ 1 ช่อง หัวคอลัมน์เป็นภาษาไทย
- คอลัมน์แรกๆ เป็นผลลัพธ์: % เหมาะกับตำแหน่งที่สมัคร, ตำแหน่งที่เหมาะที่สุด, คะแนนเข้ากับ CEO, เลขเส้นทางชีวิต, สไตล์หลัก DISC / BOSI / Enneagram, % เหมาะสมทั้ง 7 ตำแหน่ง, สัดส่วน DISC และ BOSI, คะแนน Enneagram ทั้ง 9 ไทป์
- ต่อด้วยข้อมูลใบสมัครทุกช่อง ส่วน HR และลายเซ็น
- **ไม่เก็บคำตอบรายข้อของแบบทดสอบ** เก็บเฉพาะผลลัพธ์
- แถวที่ 2 ถูกซ่อนไว้ เป็นรหัสช่องที่ระบบใช้จับคู่ข้อมูล **ห้ามแก้หรือลบ** (จะเรียง ซ่อน หรือเพิ่มคอลัมน์ของตัวเองต่อท้ายก็ได้)

เมื่อเสร็จแล้ว:
- ผู้สมัครกรอกจากมือถือที่ลิงก์ GitHub → ข้อมูลเข้า Google Sheet แท็บ "ผู้สมัคร" ทันที พร้อมสรุปผลทดสอบ % ความเหมาะสม และคะแนนเข้ากับ CEO
- HR เปิดหน้า `#hr` → ใส่รหัสผ่าน → ดูผล บันทึกสถานะ ลบ และพิมพ์ A4 ได้จากทุกเครื่อง
- ทางเลือก: ใช้ลิงก์ `/exec` ของ Google เป็นหน้าใบสมัครได้เลยโดยไม่ต้องใช้ GitHub (หน้า HR คือ `/exec?hr=1`)

ถ้าแก้ `Code.gs` ภายหลัง ต้องกด Deploy → Manage deployments → แก้ไข (ไอคอนดินสอ) → Version: New version ทุกครั้ง

### ถ้ายังไม่เชื่อม Google Sheets
หน้าเว็บจะเก็บข้อมูลไว้ในเบราว์เซอร์ของเครื่องที่กรอกเท่านั้น เหมาะกับการให้ผู้สมัครกรอกบนแท็บเล็ตของบริษัทแล้ว HR เปิด `#hr` บนเครื่องเดียวกัน
